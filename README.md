# Quatro • Pastelería Artesanal 🧁🤎

Landing web oficial y catálogo interactivo de **Quatro**, emprendimiento de pastelería artesanal creado por 4 amigos (Mati, Sofi, Vale y Thoto).

## 🚀 Páginas del Proyecto
- **Inicio / Landing Principal (`index.html`)**: Presentación del proyecto, catálogo destacado, historia del emprendimiento, testimonios y contacto por WhatsApp.
- **Alfajores Artesanales (`alfajores.html`)**: Variedad de alfajores con extra dulce de leche repostero.
- **Brownies Artesanales (`brownies.html`)**: Brownies con cacao al 70% y corazón fudge.
- **Pastafrolas Tradicionales (`pastafrolas.html`)**: Masa sablée artesanal con enrejado clásico de membrillo y batata.

## ✨ Características Técnicas
- **Navegación Elástica Dinámica**: Pastilla indicadora animada que se desliza suavemente al hacer hover y se sincroniza automáticamente con las secciones mediante *Scrollspy*.
- **Menú Frosted Glass**: Desplegable con efecto vidrio translúcido y desenfoque (`backdrop-filter`) para máxima legibilidad.
- **Transiciones Suaves**: Navegación fluida entre páginas con micro-animaciones.
- **Optimizado para Móviles**: Menú responsive interactivo y botones directos a WhatsApp para pedidos.

## 📦 Despliegue en GitHub Pages

1. Subir este repositorio a GitHub:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
   git branch -M main
   git push -u origin main
   ```
2. En GitHub, ir a la pestaña **Settings** > **Pages** de tu repositorio.
3. En **Build and deployment** > **Source**, seleccionar:
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. Hacer clic en **Save**. En unos minutos el sitio estará disponible en:
   `https://TU-USUARIO.github.io/TU-REPOSITORIO/`
